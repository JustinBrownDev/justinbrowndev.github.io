TDZ initialization-order hotfix validation
==========================================

Browser failure reproduced from prior package:
  ReferenceError: Cannot access 'sharedBenchMaterial' before initialization
  addBench -> buildArtGallery -> buildSignatureSite -> synchronous city generation

Cause:
  buildArtGallery() executes during the building-site generation loop, while
  sharedBenchMaterial was a top-level const declared later in the module.
  Function declarations are hoisted; const initialization is not.

Fix:
  sharedBenchMaterial now initializes with the early shared geometry/material
  resources, before any signature site or normal building can be constructed.

Static generation call-graph audit (TypeScript JS parser/symbol resolver):
  generation-reachable functions: 153
  late top-level const/let hazards after fix: 0

The same audit against the prior downloadable package reports exactly:
  addBench -> sharedBenchMaterial (late const)
